# Halcyon Days at Taoyuan 한국어화 패치
<img width="554" height="554" alt="image" src="https://github.com/user-attachments/assets/4c273b4a-9277-4783-b3cd-81b113a69e03" />

`Halcyon Days at Taoyuan` 비공식 한국어화 패치입니다.

## 다운로드

[최신 릴리스](https://github.com/jjpatch12/halcyon-days-at-taoyuan-korean-patch/releases/latest)에서 ZIP 파일을 받으세요.

## 현재 버전

- 패치 버전: `2026.08.19-current`
- 릴리스 태그: `v2026.08.19`

## 포함 내용

- 현재까지 검수한 전체 한국어 번역
- 편지 94종 가로쓰기 및 자동 크기·줄바꿈 조정
- 도입부 도화원 장면의 고정 중국어 문구 한국어화

## 설치

1. 게임을 종료합니다.
2. 릴리스 ZIP을 완전히 압축 해제합니다.
3. `한글패치_설치.bat`를 실행합니다.
4. 자동 검색이 실패하면 명령 프롬프트에서 게임 경로를 지정합니다.

```bat
한글패치_설치.bat "D:\게임\Halcyon Days at Taoyuan"
```

`.patch_data` 폴더에는 실제 패치 파일과 안전 설치 도구가 들어 있으므로 삭제하거나 BAT와 분리하지 마세요.

## 제거

게임을 종료한 뒤 `한글패치_제거.bat`를 실행합니다. 설치 직전에 자동 백업한 원본 7개 파일을 검증하여 복원합니다.

## 안전 기능

- 패치 및 게임 파일 SHA-256 검증
- 지원하는 게임 파일 버전인지 설치 전 확인
- 게임 실행 중 설치·제거 차단
- 원본 7개 파일 자동 백업
- 실패 시 자동 롤백
- 저장 파일은 수정하지 않음

## 파일 검증

SHA-256 값은 [`SHA256SUMS.txt`](SHA256SUMS.txt)에서 확인할 수 있습니다.

## 주의

- 게임 업데이트로 원본 파일이 달라지면 설치기가 안전을 위해 중단됩니다.
- 이 패치는 비공식 팬 번역입니다.
- 게임과 관련 자산의 권리는 각 권리자에게 있습니다.
